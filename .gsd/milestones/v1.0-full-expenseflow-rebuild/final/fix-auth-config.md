# Fix Plan: Firebase Auth Configuration

## Problem
Firebase Authentication is returning `auth/configuration-not-found` when the frontend attempts to sign in with the custom token generated by the `jwt-bridge`. This means that Identity Toolkit (Authentication) is not enabled on the Firebase project.

## Tasks

<task type="manual">
  <name>Enable Firebase Authentication</name>
  <action>
    Go to the Firebase Console -> Authentication -> Get Started. Ensure that the project is set up to allow Custom Authentication tokens.
  </action>
  <verify>Run the login flow again and verify no errors appear in the console.</verify>
  <done>The user is successfully logged in without console errors.</done>
</task>
