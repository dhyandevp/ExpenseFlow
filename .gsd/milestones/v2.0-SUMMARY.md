## Lessons Learned
- Incremental, goal-backward planning works well for standardizing a large, somewhat messy MVP.
- Maintaining strict design system tokens (`bg-surface`, `text-primary`) prevents UI debt.
- Empty states and explicit loading skeletons significantly improve perceived app quality.
